# ADR-005 — Documentation is source of truth

**Date:** 2026-10-27  
**Status:** Accepted

## Decision

Version Markdown documentation alongside code. Every important approved change updates ADRs/specs/roadmap/state/changelog as appropriate.

## Rationale

Portable context across ChatGPT, Cursor and future collaborators.

## Consequences

Docs should stay concise, linked, verifiable and separate plans from delivery evidence.
